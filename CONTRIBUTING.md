# Contributing

Thanks for helping improve Bio Roaster. Open an issue to discuss a larger change, or send a pull request for a focused fix or improvement.

## Getting started

1. Fork the repository and create a branch for your change.
2. Install dependencies with `npm install`.
3. Run the app with `npm run dev` and make your change.
4. Run `npm run lint` and `npm run typecheck` before opening a pull request.
5. Describe the change and include a screenshot for visible UI updates.

## Roast writing guidelines

- Keep jokes playful and aimed at bio clichés, formatting, or wording.
- Do not target protected traits, sensitive personal details, or the person behind the bio.
- Add new jokes to the local rule-based generator; do not add external API calls or secrets.
- Avoid including real people's personal bios in examples or screenshots without permission.
